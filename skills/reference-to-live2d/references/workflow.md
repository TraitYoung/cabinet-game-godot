# 参考图驱动的 Live2D 制作流程

## 1. 建立 T-pose 基准

指定人物、服装和画风的主参考，再制作正面、背面、侧面。完整包含头顶、脚底和双手；侧面约束轮廓和厚度，背面约束后发与服装结构。对照眼型、头发体积、头身比、衣摆和配饰位置。不同服装独立记录。

生成三视图通常不是严格正交工程图，不假定同尺度。保存原图和实际提示词。历史原图未留提示词时说明缺失，新写模板不能冒充原始提示词。

## 2. 标点与比例

原图左上角为原点，x 向右、y 向下。注明左右是画面方向还是人物方向。标记头顶、下巴、鞋底、脸颊、瞳孔、眼角/眼睑、鼻、嘴、颈部、肩关节估计、手腕、指尖、衣服/裙子下摆及可见膝部。遮挡点记为 `null`，衣服外轮廓不代替人体骨点。

```text
含鞋全高 H = sole.y - crown.y
头高 h = chin.y - crown.y
头身数 = H / h
长度归一化 = length / H
瞳距归一化 = (right_pupil.x - left_pupil.x) / face_width

s = target_shod_height / source_shod_height
x' = target_center_x + (x - source_center_x) * s
y' = target_crown_y + (y - source_crown_y) * s
```

头高不含呆毛或眼镜。面部细节还可按脸宽和瞳孔中线归一化。统一等比缩放，不为适配旧分件而单独拉宽脸或放大眼睛。

保存源图 SHA-256、尺寸、标点和误差估计。`scripts/measure_landmarks.py` 读取 `views -> {source, landmarks_px, sha256?}`，需要 Pillow，只计算已有标点，不会自动定位或修改模型：

```bash
python /path/to/reference-to-live2d/scripts/measure_landmarks.py \
  /path/to/landmarks.json --root /path/to/project \
  --output /path/to/measurements.json
```

换图后复核标点，不能只更新哈希。生成结果需单独观察/标点；目标坐标不等于生成图实际测量值。

## 3. 完整头部生成与外貌审阅

需要重绘时，以原图为唯一身份参考，先生成完整头部母图，让头型、眼型、神态、头发、明暗和配饰一起成立。并排对照原图、候选头部、当前模型；数值对齐仍可能改变人物气质。通过外貌审阅后才从同一母图原位分层，不独立生成五官再拼接。

原图脸部已认可时走另一分支：保留可见原图像素和相对坐标，生成注册的前景遮罩与隐藏皮肤底层；补画放在可见层后面。检查镜片后的头发、细发丝、眼部和嘴部周围皮肤。遮罩也需要核对。

分别标注遮罩、裁切、重绘、插值放大。实际复合像素比较才能支持像素一致结论；静态复合通过不等于动态无缝。

## 4. 参考生成自然站姿身体

T-pose 提供身材、服装和结构参考，不是站姿袖子贴片。重新绘制下倾肩线、自然锁骨/袖笼、下垂手臂的落肩位置、重力褶皱、放松肘部、袖口和手指，同时保留针织纹理、口袋、图案、配饰和衣摆。

锁定画布、统一尺度和关键高度，先看完整站姿是否自然，再分层绑定。直接旋转 T 姿袖子会保留横举时的肩角和褶皱，接缝不漏也可能不自然。

核对真实透明度、肩部轮廓、两只手、服装结构和身体比例。生成原件与提示词放入项目，保留输出 alpha；不要只引用生成器私有目录。

## 5. 组装与绑定

保留原头部时，去掉身体母图中的生成头部，并保留/补齐颈部。按脸部中线、下巴、颈宽和肩线统一注册；检查透明细缝、双重发梢、皮肤色差及运动露底。

根据当前里程碑选择身体结构：站姿/整体待机可用一块连续身体网格；独立肢体动作则从已认可站姿拆出肢体与衣身，补画腋下、袖口、关节、裙下等遮挡区，再绑定控制。不能把整体网格称为已完成手臂动画。

原生编辑工具按当前 `tools/list` 参数执行，不复用过期状态。分割/删层后核对可见列表，静态渲染必要时显式列出保留图层。自动分割产生的 Glue 可能拉动连接片，需实际检查。

没有口腔内层时保留闭嘴轮廓，不让自动口型生成抹掉整张嘴。动作幅度按网格能力设置，不靠运行时限幅掩盖基本肩部造型错误。

## 6. 导出与验收

检查 `.model3.json` 引用的 MOC3、贴图、物理、动作、表情及显示信息均存在；改文件名前缀时同步更新 JSON 相对路径。

在实际网页检查默认加载、静止站姿、待机、小幅转头、已有动作/表情、刷新后的选择、桌面/手机画布、资源状态和页面异常。另看肩线、颈部、手腕与衣身接缝。按改动运行代码检查；只换素材不必重跑无关后端测试。

分别报告文件完整、静态外貌、已测动态行为。保存截图、生成/导出参数和当前限制。参数数量和脚本通过不能代替外貌审阅。

## 7. 已有模型的接缝返工与后续控制

当用户指出脸部拼接、眨眼露洞或运动开裂时，续接[头部接缝返工](seam-repair.md)：先复现近景，检查 alpha、隐藏皮肤、柔边五官和变形器父链，再修眨眼与颈部重叠，导出并回到真实网页。不要重跑已经认可的 T-pose 和身体生成，也不要把静态像素一致当作动态通过。

若选择连续头部暂时减少独立控制，明确交付边界；之后按有补画的发片、有效遮罩的虹膜及口腔内层逐项恢复，并重测组合姿态。
