# 头部接缝、眨眼与后续绑定

适用于已有模型的脸部贴片感、头发/五官开裂、闭眼露洞和颈部断开。保留认可的人物与身体，从发生问题的阶段继续。

## 1. 先把故障复现为近景

分别查看原图、分层复合、原生编辑器中立姿态及运动姿态。覆盖睁眼、半闭眼、闭眼、左右转头、抬低头、侧倾，以及转头与眨眼组合；每套服装单独检查。保存镜头、参数和实际截图。SDK 参数值不等于测得的空间旋转角度。

- 中立姿态已有块状边界：检查硬切皮肤、alpha、网格覆盖、层序和遮罩。
- 中立姿态正常，运动时开裂：检查遮挡补画及相邻部件的变形器父链，尤其脸部轮廓、鼻口、发片和配饰的额外位移。
- 半闭眼露出矩形洞：眼部纹理可能携带整块皮肤，底图没有完整皮肤承接。
- 开合参数改变但眼睛不动：检查实际语义分类、生成后的对象与参数绑定，不能只相信输入层名。

先区分素材、绑定与运行时渲染故障。替换播放引擎不能自动修复贴图孔洞或错误变形链；只有证据指向运行时问题时，才比较引擎行为。

## 2. 补齐每套头部自己的隐藏皮肤

从实际母图裁切完整头部，记录原图坐标与尺寸。生成移除眼睛、睫毛、眉毛后的连续皮肤，保留鼻口、轮廓、头发、配饰与构图；只把需要的补画用在隐藏区域，不能直接用生成的整张脸替换已认可五官。每套母图的色调和遮挡不同，不默认跨服装复用旧皮肤板。

检查生成图的真实尺寸、注册和内部 alpha，再缩放回参考尺寸。重采样不是增加原画细节。补画配准有误时先修注册，不通过移动原画五官迁就它。

支持差异提取的编辑器可按以下顺序制作：

1. 以原图、去五官补画和局部区域遮罩，提取柔边眼睛或眉毛；每次继续处理上次留下的底图。
2. 让底图覆盖五官移动后露出的完整区域，检查柔边周围的肤色、残留睫毛及发丝；不要保留矩形皮肤边框。
3. 检查半透明原图在差异提取后是否产生透明皮肤孔洞。通过原生绘制或补画修复，并保存实际修复操作。
4. 复合检查静态外貌，再检查闭眼时底图是否完整。静态复合一致不能替代这一步。

工具操作前读取当前 schema。PSD2Live 可使用 `material_crop`、`material_preview`、`material_peel` 和原生绘制；区域遮罩、差异阈值、颜色匹配和 alpha 修复取决于实际图片。先检查导出的 PNG，不能因 SVG 或导出调用成功就认为像素存在。

## 3. 修正共享运动和眨眼

让相邻可见面在头部运动中连续。检查自动绑定附加的轮廓、鼻尖、五官位移和头发跟随形变是否把接缝两侧拉开。需要时重绑定到协调的父变形器，并保留眼眉的局部控制。

连续头部表面是可选的阶段方案：把头发、脸、鼻口与配饰合成连续表面，原画眼眉另层运动，可以先解决裂缝。但这会减少独立发丝或虹膜控制，必须明确报告，不能宣称完成完整头部绑定。

眨眼要逐段检查：睁眼保持原画，半闭眼不能露底，闭眼保留合适的眼睑线。单独绘制闭眼线时，避免它与被压扁的原眼图层同时显示形成双线，也避免过长透明度淡化造成幽灵眼。显隐阈值按实际网格与动画调节，不复制另一模型的数值。没有口腔内层时保留闭嘴原画，不添加伪口型。

## 4. 补颈部并回到真实网页

补画下巴后方、颈侧和领口的重叠区域；可以在原画可见颈部后加隐藏补画，避免覆盖认可的衣领。转头、抬头和侧倾时分别检查，不能只扩大一张矩形皮肤板后结束。

保存独立可编辑工程和旧运行资源，再导出。核对模型所有相对引用，重新检查生成后的实际对象、分类和绑定。源模型验证通过后，移除只为旧模型掩盖脸部故障的限幅或嘴部补丁；按能力保留必要的身体动作设计。

在真实网页复核两套模型、默认选择、刷新、已有动作/表情、桌面与手机，并保存近景及资源/页面错误记录。生产服务可能缓存构建清单：若重新构建后旧服务请求过期 chunk，应先核实进程归属再重启该服务，不能把页面资源 500 误判为模型缺陷。

## 5. 后续恢复自由度

在已验收的连续头部上逐项恢复：有发下补画的独立发片与物理；眼白、虹膜、睫毛和有效裁剪遮罩；口腔、牙齿、舌头及开合口型。每增加一项，都检查中立姿态、参数极值及组合动作，再接对话、情绪或 TTS 驱动。不因为源文件存在某个参数就宣称对应能力已完成。

交付区分三件事：旧缺陷修复了什么、当前动态验收覆盖什么、仍未恢复哪些独立控制。注明实际使用的编辑工具与导出格式，不能把 PSD2Live 导出 `.cmo3` 写成已经在官方 Cubism Editor 精修。
